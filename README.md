# Bookmark Swipe

日本語 | [English](README.en.md)

X（Twitter）のブックマークを、カードをスワイプして1枚ずつ整理する Chrome 拡張（Manifest V3）です。

## 読み込み方
1. `chrome://extensions` を開き、右上の「デベロッパー モード」をオン
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダ（`x-bookmark-swipe`）を選ぶ
3. `https://x.com/i/history` を開く

## 使い方
ブックマークページの画面下中央に出る「スワイプで整理」を押すと全画面で起動します。カードはシャッフルされた順に出ます。操作は絵と記号でわかるようにしてあり、ブラウザの言語に合わせて日本語と英語を切り替えます。
カードを動かすと、方向ごとの丸い判子（外す 👋、残す 🤝、フォルダへ 📁、あとで ⏳）が浮かび上がります。

| 操作 | ドラッグ | キー | 結果 |
|---|---|---|---|
| 外す | 左へ | ← / D | ブックマーク解除（4秒の猶予つき） |
| 残す | 右へ | → / K | 確認済みとして記録（次回以降は出さない） |
| フォルダへ | 上へ | ↑ / F | フォルダを選ぶ（数字キー 1〜9、Esc で戻る） |
| あとで | 下へ | ↓ / S | 山札のランダムな位置に戻す |
| 元に戻す | トースト／下のボタン | Z / ⌘Z | 何度でも可 |
| Xで開く | カードのリンク | Space / O | 新しいタブ |
| おわり | 右上の「× おわり」 | Esc | 未送信の操作は閉じるときに即送信 |

- 右上の成果表示は `👋 24  🤝 51`（外した件数・残した件数）です。
- 残り件数の「132+」の `+` は、まだ全件を読み込み中という意味です（裏でページを自動スクロールして読み込みます）。
- 設定（右上のスライダーアイコン）で「確認済みもすべて表示」と記録のリセットができます。
- 「外す」は猶予内なら通信なしで取り消せます。送信後の取り消しは再ブックマーク（ブックマーク一覧での並びは先頭に変わります）。

## 開発用ページ（ログイン不要）
```
cd dev
python3 -m http.server 8765
# http://localhost:8765/ を開く
```
`fixture.json`（30件）を本物のパーサに通して、3ページに分けて遅延読み込みします。書き込みはモックです。クエリ：`?theme=dark|light`、`?lang=ja|en`、`?folders=0`、`?fail=0.4`、`?batch=30`、`?nodelete=1`、`?empty=1`。`dev/src` は `../src` へのシンボリックリンクです。

## 注意
X の**非公開の Web API**（GraphQL）に依存しています。X 側の変更で、予告なく動かなくなることがあります。通信は x.com（と、queryId 探索のための X 公式の `abs.twimg.com` のスクリプト取得）以外には一切行いません。自己責任でお使いください。
